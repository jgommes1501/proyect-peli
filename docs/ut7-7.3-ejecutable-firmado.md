# UT7 - 7.3 Generando el Ejecutable Firmado (AAB)

## Objetivo
Generar el archivo firmado para Google Play en formato AAB.

## APK vs AAB
- APK: paquete completo para todos los dispositivos.
- AAB: paquete optimizado; Google Play genera APKs por dispositivo/idioma.

## Flujo implementado en este proyecto

1. Preparar build de produccion y sincronizar:

```bash
npm run android:prepare:prod
```

2. Inicializar archivo local de firma (solo una vez):

```bash
npm run android:keystore:init
```

3. Editar `android/signing.properties` con datos reales:

```properties
storeFile=C:\\ruta\\a\\tu\\keystore.jks
storePassword=TU_PASSWORD
keyAlias=TU_ALIAS
keyPassword=TU_PASSWORD
```

4. Generar bundle release firmado:

```bash
npm run android:bundle:release
```

Salida esperada:
- `android/app/build/outputs/bundle/release/app-release.aab`

## Variante Android Studio (equivalente)
- Build > Generate Signed Bundle / APK
- Seleccionar Android App Bundle
- Elegir/Create keystore
- Build variant: `release`

## Seguridad (obligatorio)
- `android/signing.properties` y archivos de keystore estan excluidos en `.gitignore`.
- Si pierdes la keystore, no podras actualizar la app en Google Play.
